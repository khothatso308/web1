# Cathy's Cakes Website — WEDE5020 POE Part 2

Welcome to the official repository for Cathy's Cakes, a bakery website made for our store at Wonderpark Estate in Karen Park, Pretoria. This project is submitted for the Introduction to Web Development (WEDE5020) module.

1 Project Overview

The goal of this project is to create a clean, easy-to-use website for Cathy's Cakes. The website allows customers to view our bakery products, check prices, learn about custom cake orders, find our contact information, and view our location on a map.

---

2 File Structure

* index.html: Home page featuring current promotions and bakery highlights
* aboutus.html: Background story and history of Cathy's Cakes
* productsgallery.html: Full catalog showing our cakes, cupcakes, and cake pops
* ordernow.html: Online order form for custom cakes
* CONTACT US.html: Phone number, email, social links, and embedded Google Map
* CSS/style.css: Main stylesheet used across all pages
* IMAGES/: Folder storing all photos, logos, and icons

---

 3Summary of Changes and Changelog

Based on feedback from Part 1, we made several important updates to improve the website:

1. Connecting the Stylesheet
We fixed the stylesheet link across all HTML pages so that CSS styles apply everywhere without breaking.


2. Fixing HTML Tags
We replaced incorrect custom tags like p1, p2, and u1 with standard HTML tags like p and ul so browsers read the code correctly.
3. Image Sizes
We added CSS rules to stop images from overflowing their cards and boxes, keeping all photos neatly aligned.
4. Better Links and Contact Info
We fixed broken page links, added clickable phone numbers and email links, and added a live Google Map for our shop location.


5. Mobile Friendly Design
We added CSS media queries so the website rearranges automatically on smaller screens like phones and tablets.

---

 4Features and Design Elements

* Matching Colors: Soft pastel colors chosen to fit the bakery theme.
* Responsive Gallery: Product grids that automatically wrap into rows based on screen width.
* Phone Friendly: Page layouts stack vertically so mobile users can browse easily.
* Interactive Buttons: Buttons and links change color when you hover over them.

---

 5 How to Run the Project

1. Download or clone this folder to your computer.
2. Make sure the IMAGES folder and CSS folder are kept in the same main directory as your HTML files.
3. Double-click index.html to open the website in your web browser.
